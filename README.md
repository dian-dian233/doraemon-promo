# doraemon-promo

哆啦A梦 · 来自 22 世纪的猫型机器人 —— 一个单页介绍页。

## 里面讲什么

三块内容：

1. **哆啦A梦本人**：蓝白红的配色、四次元口袋，以及这个角色是怎么被设计出来的
2. **四件经典道具，四种「当时要是有就好了」**：任意门、竹蜻蜓、记忆面包、时光机，挨个说他解决的到底是什么遗憾
3. **为什么是哆啦A梦**：一个来自 22 世纪的猫型机器人，为什么被记了这么多年

## 用法

下载 `index.html` 双击打开，或者直接看 GitHub Pages。

单文件 40 KB，**不挂任何 CDN**，断网也能正常显示。

## 特点

- 纯 HTML + CSS，样式全部内联，没有构建步骤
- 无框架、无外部字体、无第三方脚本
- 手机和桌面都能看
